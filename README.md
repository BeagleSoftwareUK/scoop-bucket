# Beagle Software Scoop bucket

```powershell
scoop bucket add beagle https://github.com/BeagleSoftwareUK/scoop-bucket
scoop install beagle
```

Installs [beagle](https://github.com/BeagleSoftwareUK/beagle-cli), Beagle CRM from the terminal. This repository is updated automatically when a new version is released.
